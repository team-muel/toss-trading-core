# ALFRED 시점 데이터 기반 거시경제 레짐 연구

## 목적

FRED의 현재 최신값을 과거 모든 시점에 적용하면 당시에는 알 수 없었던 수정치가
백테스트에 들어간다. 이 연구 계열은 ALFRED의 `realtime_start`가 각 값의 공개
빈티지라는 점을 이용해, 매 거래일에 실제로 공개돼 있던 버전만 복원한다.

이 계열은 전략 실행 권한을 갖지 않는다. 다른 후보와 똑같이 워크포워드,
SPY 대비 블록 부트스트랩, Bonferroni 다중검정 보정, 거래비용 2배 스트레스,
봉인된 전향 검증을 모두 통과해야 한다.

## 수집과 캐시

- 주간 실행은 2004-01-01부터 현재까지 승인된 FRED 계열의 ALFRED 수정 이력을
  3년 이하 빈티지 구간으로 나누어 전부 갱신한다.
- 일간 실행은 최근 90일의 신규·수정 빈티지만 요청하고 주간 전체 이력 캐시와
  합친다.
- 캐시가 없거나 증분 구간과 이어지지 않으면 일간 실행도 전체 이력을 자동으로
  재구축한다.
- 캐시 원본은 매 실행의 데이터 레이크에 현재 코드 리비전으로 다시 등록된다.
  따라서 평가 결과의 `data_manifest_ids`로 가격과 거시 원본을 함께 추적할 수 있다.
- API 키는 캐시와 매니페스트에 기록하지 않는다.

## 허용된 계열과 신호

현재 권리 검토를 통과한 데이터만 사용한다.

| 신호 | 입력 계열 | 위험 선호 방향 |
|---|---|---|
| 수익률 곡선 | DGS10 - DGS2 | 양수 |
| 물가 추세 | CPIAUCSL 전년비의 3·6·12개월 변화 | 하락 |
| 고용 추세 | UNRATE의 3·6·12개월 변화 | 하락 |
| 정책금리 추세 | FEDFUNDS의 3·6·12개월 변화 | 하락 |

AI는 코드를 만들 수 없으며 다음의 제한된 값만 조합한다.

- 위험 선호 ETF: 정책에 등록된 승인 ETF 중 2개 이상
- 방어 ETF: SGOV를 반드시 포함하고 TLT·GLD만 추가 가능
- 네 거시 신호의 가중치: 0, 0.25, 0.5, 0.75, 1.0
- 변화 관측기간: 3, 6, 12개월
- 레짐 기준값: -0.25, 0, 0.25
- 리밸런싱: 월간 고정

## 미래정보 방지 규칙

1. 각 관측일마다 `realtime_start`가 가장 늦으면서 의사결정일까지 공개된
   값만 선택한다.
2. 발표 시각을 날짜 단위 API로 완전히 증명할 수 없으므로 공개 빈티지에
   1일의 보수적 지연을 더한다.
3. 수정 빈티지가 아직 공개되지 않은 과거 시점에는 이전 버전을 유지한다.
4. 월말 종가 시점에 레짐을 계산하고 목표 비중은 다음 거래일에만 적용한다.
5. 결측치나 필요한 과거 관측치가 부족하면 신호를 추정하지 않고 리밸런싱을
   건너뛴다.

## 포트폴리오 규칙

활성 신호의 가중평균 점수가 가설의 기준 이상이면 위험 선호 바스켓을,
그보다 낮으면 방어 바스켓을 동일가중한다. 임의 회귀식, 사후 최적화된 계수,
LLM이 만든 코드나 외부 데이터는 허용하지 않는다.

## 메일에서 확인할 내용

메일의 자율 연구 섹션에 `macro_regime` 계열, 경제적 가설, 반증 조건,
사용한 신호 가중치, 변화 관측기간, 위험·방어 자산, 실패한 검증 게이트가
그 실행 결과로 표시된다. `historical_not_qualified` 후보는 발견된 전략이
아니며 재검정 또는 승격되지 않는다.

## 현재 한계

- ALFRED API는 날짜 단위 공개 시점을 제공하므로 1일 지연으로 보수 처리한다.
- 현재 거시 계열은 미국 금리·물가·고용에 한정된다.
- 발표 예상치나 서프라이즈는 신뢰할 수 있는 시점 데이터가 없어 사용하지 않는다.
- 거시 레짐은 저빈도 신호이므로 일중 전략 연구에 사용하지 않는다.
